# State Weaver

Build a fully functional, highly efficient, and innovative web application named "Distributed State Migrator" designed for zero-downtime multi-tenant schema migrations. 

- Features: Real-time visual node sync dashboard, automated lock-free transaction queue simulation, and live rollback logs.

- UI & Theme: Modern, sleek medical/tech-grade UI featuring a fully working global Theme Switcher for Dark Mode, Light Mode, and System Default preference.

- Requirements: Zero broken links, fully interactive buttons, robust error-handling, mock database state storage (via LocalStorage/Context), and high performance.
